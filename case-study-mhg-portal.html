01 Overview

One Platform to Run
All Letting Operations.

More Homes Group needed a single platform to run day-to-day agency operations without switching between disconnected tools. We built a centralised portal combining business workflows, communication, and compliance in one system.

The Problem

Fragmented tools, limited visibility, and weak communication flow between teams.

  • Records stored separately
  • Limited activity visibility
  • No dialer workflow
  • Weak login security

The Solution

A centralised Next.js operations portal combining workflows, communication, and compliance.

  • Role-based architecture
  • OTP-protected login
  • Unified data model
  • Integrated dialer suite

Delivered Outcomes

A fully operational letting portal serving admin and agent users from a single secure system.

  • Single source of truth
  • Faster admin oversight
  • Stronger security
  • Audit-ready
02 Core modules

Every Part of the
Portal, in Detail.

The system is organised into five core modules, each handling a distinct area of the letting business — from admin oversight and agent workflows through the dialer suite, team communication, and revenue reporting.

01 — Admin Control Center

The admin-only hub for managing the entire platform — agents, commission structures, dialer domain settings, audit logs, and full portfolio visibility.

  • Agent account management
  • Commission configuration
  • Dialer domain settings
  • Platform-wide audit log
  • Full portfolio visibility
  • Role & permission management

02 — Agent Workspace

The day-to-day operational hub for agents — onboarding landlords, managing property lifecycles, closing sales, and maintaining tenant records.

  • Landlord onboarding
  • Property lifecycle tracking
  • Sales record management
  • Tenant record tracking
  • Assigned portfolio view
  • Commission & payment status

03 — Dialer Suite

A fully integrated calling workflow built directly into the portal — SIP/LINKUS-ready, covering the complete calling experience from dial to post-call notes.

  • Live call status dialpad
  • Contacts management
  • Full call history
  • Intercalling (extension-to-extension)
  • Labels & favourites
  • Recording URL support

04 — Team Communication

An embedded chat system for fast internal coordination between users — no switching to external tools, keeping communication in context and on record.

  • Direct messaging
  • Real-time delivery
  • Conversation history
  • Presence & online status
  • Unread indicators
  • Admin & Agent access

05 — Revenue & Performance

Sales and commission dashboards giving admins and agents clear visibility into financial performance and portfolio activity.

  • Sales dashboard
  • Commission dashboard
  • Revenue overview
  • Operational reporting
  • Agent performance summaries
  • Filterable date-range reporting
03 Architecture

Built on a Modern
Full-Stack Foundation.

  • Next.js 14
  • React 18
  • TypeScript
  • Prisma ORM
  • PostgreSQL
  • Zod
  • SIP.js
  • Vercel / Docker

Next.js 14 + React 18

App Router with server and client components, TypeScript throughout, Server Actions for mutations, and a Vercel-ready deployment.

Prisma ORM + PostgreSQL

A type-safe ORM over PostgreSQL with a clean unified data model, migration management via Prisma Migrate, and Zod validation.

SIP.js Dialer

Browser-based calling via SIP.js, LINKUS-ready architecture for enterprise PBX, live call status, and extension-to-extension intercalling.

Security & Authentication

OTP-based login with expiry and rate limiting, secure server-side sessions, and a two-tier role model with route protection and audit logs.
